VS Code extension · v{{VERSION}}

Read your secrets
without unsealing them.

SOPS Lens decrypts .enc files in the editor — CodeLens, hover, or ghost-text. It calls the sops CLI in memory. The plaintext never lands on disk, never hits your terminal scrollback, never gets git add-ed by accident.

Download .vsix Get it on Open VSX

code --install-extension sops-lens-{{VERSION}}.vsix

.env.enc reveal 
DB_PASSWORD=ENC[AES256_GCM,data:9fZ2..·
STRIPE_KEY=ENC[AES256_GCM,data:pLq8..·
JWT_SECRET=ENC[AES256_GCM,data:Tv13..·
AGE_RECIPIENT=ENC[AES256_GCM,data:Rm0z..·
sops -d · in-memory
